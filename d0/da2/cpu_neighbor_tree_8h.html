Detailed Description

Простое дерево для точного поиска соседей в заданном радиусе на CPU.

Точки упорядочиваются по мортоновским кодам и разбиваются на листья по leafSize точек; над листьями строится полное бинарное дерево габаритных прямоугольников. Используется для расчета сумм с компактным носителем (диффузионные скорости I1, I2), результат совпадает с прямым перебором с точностью до порядка суммирования.
